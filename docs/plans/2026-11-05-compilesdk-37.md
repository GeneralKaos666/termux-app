# compileSdk 37 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise `compileSdkVersion` 36→37 with Robolectric 4.17 as the test-runtime prerequisite, then land the four dependency bumps that compileSdk 37 unblocks.

**Architecture:** Six signed commits. Task 1 bumps Robolectric (the only change that makes unit tests compile against `android-37`). Task 2 raises `compileSdk`. Tasks 3–6 bump one dependency each, ascending blast radius, `compose-bom` last. No source file changes; every task gates on a green build.

**Tech Stack:** Gradle 9.3.1, AGP 9.1.1 (built-in Kotlin), compileSdk 37 (platform `android-37.0`), Robolectric 4.17, NDK 29 (local workaround `-PndkVersion=30.0.16248370`).

**Spec:** `docs/specs/2026-11-05-compilesdk-37-design.md`

## Global Constraints

- `targetSdkVersion=28` and `minSdkVersion=23` never change.
- No application or library source file changes in any task.
- The three library modules keep `defaultConfig.aarMetadata.minCompileSdk = 1`; `hiddenapibypass`, `core` and the Compose artifacts are `implementation`, never `api`.
- Every commit is GPG-signed; commit types use the capitalized Conventional Commits form (`Changed(...)`).
- Every commit that changes a resolved Maven artifact carries a regenerated `gradle/verification-metadata.xml`. Task 2 adds no Maven artifact and must not touch that file.
- Local commands carry `-PndkVersion=30.0.16248370`; CI uses the pinned NDK 29 and no flag.
- The full verification-metadata regeneration command is:

```bash
./gradlew --write-verification-metadata sha256 help test lint \
  :app:assembleDebug :app:assembleRelease \
  :termux-shared:assembleDebugAndroidTest :terminal-view:assembleDebugAndroidTest \
  :termux-shared:assembleRelease :terminal-view:assembleRelease :terminal-emulator:assembleRelease \
  :termux-shared:publishToMavenLocal :terminal-view:publishToMavenLocal :terminal-emulator:publishToMavenLocal \
  -PndkVersion=30.0.16248370
```

After regenerating, re-run the same task list **without** `--write-verification-metadata`; a
`Dependency verification failed` error means the file is incomplete.

## Review Focus

- **Test count must stay 701, never silently drop.** `./gradlew test` = 701 methods, 0 failures/errors. A zero-test or reduced run is a failure: Robolectric 4.17 is the thing being introduced, and a silent test-skip hides it.
- **The five released APK names.** `termux-app_<tag>_<abi>.apk` for `universal`, `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`. Task 6 re-checks packaging because it is the last commit that can disturb it.
- **`lint` must stay green.** CI runs `./gradlew lint`; the compileSdk raise (Task 2) is the kind of change that can surface new checks. Do not add a `baseline.xml` or `@SuppressLint` without explicit approval.
- **Published AAR floor stays `minCompileSdk=1`.** Task 2 re-checks each release AAR's `aar-metadata.properties` so a compileSdk 37 build cannot accidentally advertise a 37 floor to companion apps.
- **Release mapping keeps the three library packages.** Task 2 and Task 6 run `:app:assembleRelease`; the mapping must still name `com.termux.shared`, `com.termux.view`, `com.termux.terminal`.
